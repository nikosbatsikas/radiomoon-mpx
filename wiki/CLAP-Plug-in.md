# CLAP Plug-in

"RadioMoon MPX Transmitter" for audio programs that load CLAP plug-ins (REAPER, Bitwig Studio, FL Studio, Studio One ...). On the master track the audio passes through unchanged and the plug-in sends the multiplex with the Transmitter's settings (IP targets, card, RDS, Compact MPX, SFN, protection).

Install: Windows setup option (Common Files\CLAP), Linux `~/.clap`, macOS `~/Library/Audio/Plug-Ins/CLAP`. Settings: in the Transmitter window, which shows **PLUG-IN** and the live status. Any host sample rate.
