# Web Interface

The headless editions ([[Headless and Web Interface]]) are set up in a browser: `http://<address>:8080` (Transmitter) and `:8081` (Receiver). The tabs are the same as in the windows.

## Login
![Login](images/screens/web-receiver-login.png)

User `admin` and the password set at installation (change it in the tab **Login**). 10 wrong passwords lock the address for 5 minutes.
